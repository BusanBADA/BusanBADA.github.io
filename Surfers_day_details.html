Surfer's Day

C 기반 Hyper-Casual Obstacle Dodging Game

C Game Programming Team Leader 3 People 1 Month
// 01 — OVERVIEW

About the Project

Surfer's Day는 장애물을 피하며 최대한 높은 점수를 기록하는 Hyper-Casual 게임입니다.

2인 팀 프로젝트로 진행했으며, 저는 Team Leader이자 Programmer로서 게임의 전체적인 프로그래밍을 담당했습니다.

C 언어를 기반으로 게임 플레이에 필요한 핵심 시스템을 직접 구현하고, 아티스트와 협업하여 UI와 게임의 전체적인 플레이 경험을 완성했습니다.

// 02 — RESPONSIBILITIES

What I Worked On

01

Input System

플레이어 입력 처리 및 게임 컨트롤 구현

02

Collision Detection

플레이어와 장애물 간 충돌 판정 및 처리

03

Character State

캐릭터 상태 관리 및 상태 전환 시스템 구현

04

Game State

게임 시작, 진행, 종료 및 결과 상태 관리

05

Score System

진행 거리와 아이템, 속도에 따른 플레이어 점수 계산 및 기록 시스템 구현

06

Random Obstacles

게임 플레이에 따른 랜덤 장애물 생성 시스템을 구조체 배열로 오브젝트 풀링처럼 구현

07

UI

아티스트와 협업하여 게임 UI 구현 및 연동

08

Animation

캐릭터 및 게임 오브젝트 애니메이션 기능 구현 드론과 캐릭터 줄 연결을 속도에 따라 2차함수로 구현 물보라 이팩트를 수학으로 구현
