Project MF

Blue Archive Fan Game를 위한 UI/UX 및 3D Environment Prototype

Project MF Prototype UI / UX 3D Environment Unreal Engine 2026
// 01 — OVERVIEW

Project MF Prototype

Project MF는 Blue Archive를 기반으로 한 팬 게임 프로젝트로, UI/UX와 3D Environment 포지션 지원을 위한 포트폴리오 목적으로 제작한 프로토타입입니다.

단순히 게임의 화면을 구현하는 것보다 원작의 시각적 특징을 유지하면서도 FPS 게임에서 익숙하게 사용할 수 있는 메뉴 인터랙션과 사용자 경험을 구현하는 것을 목표로 했습니다.

또한 UI뿐만 아니라 3D 환경 모델을 함께 제작하여 하나의 게임 화면 안에서 UI와 3D Environment가 자연스럽게 연결될 수 있도록 구성했습니다.

// 02 — UI / UX

FPS-Oriented UI / UX

UI는 Blue Archive 팬 게임이라는 점이 즉각적으로 전달될 수 있도록 원작의 디자인적인 특징을 참고하여 구성했습니다.

동시에 FPS 게임의 메뉴에서 일반적으로 사용되는 인터랙션 패턴을 적용하여 사용자가 별도의 학습 없이도 메뉴를 사용할 수 있도록 설계했습니다.

메뉴 이동과 버튼 선택 등 주요 UI 요소에는 마우스 입력에 대한 시각적인 피드백을 추가하여 사용자의 입력과 UI의 반응이 명확하게 연결되도록 했습니다.

// 03 — INTERACTION EFFECT

Mouse Click & Trail Effect

UI의 조작감을 강화하기 위해 Widget 영역에서 발생하는 마우스 클릭 및 이동 궤적을 시각화하는 효과를 구현했습니다.

사용자의 입력 위치를 기반으로 Widget 영역에 효과를 표시하여 단순한 버튼 입력을 넘어 화면 자체가 사용자의 입력에 반응하는 인터랙션을 구성했습니다.

이러한 효과를 통해 UI를 사용하는 과정에서 사용자의 시선을 유도하고 입력에 대한 즉각적인 피드백을 제공하는 것을 목표로 했습니다.

// 04 — 3D ENVIRONMENT

Toon-Shaded Environment

UI/UX뿐만 아니라 게임의 배경이 되는 3D Environment 모델도 함께 제작했습니다.

원작의 그래픽 스타일과 어울릴 수 있도록 Toon Shading을 적용하는 것을 고려하여 모델의 형태와 구조를 단순화하고 게임 환경에서 사용하기 적합하도록 구성했습니다.

이를 통해 UI 디자인과 3D 환경이 서로 다른 스타일로 보이지 않고 하나의 프로젝트 안에서 일관된 시각적 방향성을 유지하도록 했습니다.

// 05 — DESIGN APPROACH

Design Approach

프로젝트를 제작하면서 가장 중요하게 생각한 부분은 원작의 특징과 사용성을 동시에 유지하는 것이었습니다.

원작의 디자인 요소를 그대로 복제하기보다는 팬 게임이라는 정체성이 드러나는 요소를 유지하면서 FPS 장르에서 익숙한 메뉴 구조와 인터랙션 방식을 결합했습니다.

또한 UI 화면만 독립적으로 만드는 것이 아니라 실제 게임에서 사용되는 상황을 고려하여 3D 환경과 함께 테스트할 수 있는 형태로 프로토타입을 구성했습니다.

// 06 — KEY FEATURES

Main Features

01

Blue Archive Style

원작의 시각적 특징을 참고하여 팬 게임이라는 정체성을 UI 디자인에 반영했습니다.

02

FPS UX

FPS 게임에서 익숙하게 사용되는 메뉴 인터랙션 방식을 적용하여 직관적인 UX를 구성했습니다.

03

Mouse Feedback

Widget 영역에서 마우스 클릭과 이동 궤적을 시각화하여 입력에 대한 피드백을 강화했습니다.

04

3D Environment

Toon Shading에 적합한 3D 환경 모델을 제작하여 프로젝트의 시각적 완성도를 높였습니다.

// 07 — DEVELOPMENT INSIGHT

What I Learned

이번 프로젝트를 통해 UI를 단순히 화면을 구성하는 요소로 바라보는 것이 아니라 사용자의 입력과 게임 시스템 사이를 연결하는 인터페이스 로 바라보게 되었습니다.

특히 FPS 게임에서 사용자가 이미 익숙하게 알고 있는 인터랙션 패턴을 활용하면 별도의 설명 없이도 자연스러운 UX를 제공할 수 있다는 점을 확인했습니다.

또한 UI와 3D Environment를 함께 구성하면서 개별적인 요소의 완성도뿐만 아니라 전체 프로젝트의 시각적인 일관성을 유지하는 것이 중요하다는 점을 경험했습니다.

// 08 — SUMMARY

Project Summary

Project MF는 Blue Archive 팬 게임을 가정하여 UI/UX와 3D Environment를 함께 구현한 프로토타입 프로젝트 입니다.

UI에서는 원작의 디자인 특징과 FPS 장르의 익숙한 UX 패턴을 결합했으며, 마우스 입력에 대한 시각적인 피드백을 추가하여 인터랙션의 완성도를 높였습니다.

3D Environment에서는 Toon Shading에 적합한 형태와 스타일을 고려하여 원작과 어울리는 게임 환경을 구성했습니다.

결과적으로 하나의 프로젝트 안에서 UI 디자인, 사용자 경험, 인터랙션, 3D Environment 제작 을 함께 경험할 수 있었던 프로토타입입니다.
