Plane Movement

Unreal Engine 기반 Airplane Movement Prototype

Unreal Engine C++ Vehicle Aircraft Prototype Solo Project 3 Days
// 01 — OVERVIEW

About the Prototype

Arsenal 프로젝트에서 대공 무기와 미사일 시스템을 테스트하기 위한 공중 이동 타겟 을 제작하는 것을 목표로 개발한 Airplane Movement Prototype입니다.

지상에서 움직이는 차량과 달리 항공기는 Throttle을 통한 속도 조절과 Yaw, Pitch, Roll을 이용한 3차원 이동이 필요하기 때문에 이를 Unreal Engine에서 직접 구현했습니다.

항공기의 기본적인 움직임을 구현하여 플레이어가 직접 조종할 수 있도록 구성했으며, 대공포나 미사일의 테스트 대상으로 사용할 수 있도록 비교적 자유롭게 공중을 이동할 수 있도록 설계했습니다.

기본적인 이동은 부드럽게 동작하지만 네트워크 환경에서는 항공기의 움직임을 클라이언트에서 예측하여 보간하는 방식이 필요하다는 점도 확인했습니다.

// 03 — NETWORK CONSIDERATION

Client Prediction

Prototype에서는 로컬 환경에서 항공기의 이동과 회전을 부드럽게 처리하는 것을 우선적으로 구현했습니다.

하지만 실제 Multiplayer 환경에서는 서버에서 전달되는 Movement 정보를 그대로 적용할 경우 네트워크 지연으로 인해 움직임이 끊겨 보일 수 있습니다.

이를 해결하기 위해 클라이언트에서 입력을 기반으로 항공기의 움직임을 먼저 예측하고 서버의 결과와 동기화하는 Client Prediction 구조가 필요하다는 점을 확인했습니다.

따라서 이후 실제 네트워크 환경으로 확장할 경우 Movement Prediction과 Server Reconciliation을 적용하는 것을 고려할 수 있도록 구조를 구성했습니다.

// 04 — SUMMARY

Project Summary

이 프로젝트에서는 Unreal Engine을 이용하여 Throttle, Yaw, Pitch, Roll을 기반으로 하는 기본적인 항공기 조작 시스템을 구현했습니다.

특히 지상 차량과 달리 3축 회전을 이용하는 항공기의 특성을 고려하여 자유로운 공중 이동이 가능하도록 구성했습니다.

또한 Arsenal 프로젝트에서 대공포와 미사일 시스템을 테스트하기 위한 공중 타겟으로 활용할 수 있도록 빠르게 Prototype을 제작하고 실제 조작감을 확인하는 것을 목표로 했습니다.
