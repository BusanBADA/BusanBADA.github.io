Tree Based Gun

Unreal Engine 기반의 Tree Structure Gun Modding System

Unreal Engine C++ Gun Modding Data Structure MVVM UI / UX
// 01 — OVERVIEW

About the Project

Tree Based Gun은 총기의 부품과 장비를 트리 구조로 관리하고 이를 기반으로 총기 모딩 시스템을 구현한 프로젝트입니다.

프로젝트의 핵심 목표는 단순히 총기의 부품을 교체하는 기능을 만드는 것이 아니라, 총기뿐만 아니라 캐릭터와 다양한 장비에도 확장할 수 있는 범용적인 데이터 구조를 만드는 것이었습니다.

각 아이템은 Primary Data Asset으로 관리하고, 실제 런타임에서 사용하는 ItemObject는 부모-자식 관계의 트리 구조를 구성합니다. 이를 통해 소켓과 부품의 계층 구조를 유연하게 표현할 수 있도록 설계했습니다.

또한 저장된 Layout을 다시 불러올 때 데이터 구조가 변경되더라도 기존 데이터를 최대한 유지할 수 있도록 기본값을 활용하는 구조를 구현했습니다.

// 02 — IMPROVEMENT

What I Tried to Improve

Arsenal 프로젝트에서 가장 아쉬웠던 부분은 총기와 장비의 모딩 시스템을 보다 완성도 높게 구현하지 못했다는 점입니다.

특히 원래 목표했던 장비 구조는 캐릭터의 Layout을 기준으로 장갑, ADS, IRCM, 반응장갑, 탄약고 등 다양한 장비를 Tree 형태로 구성할 수 있도록 확장하는 것이었습니다.

프로젝트 기간의 한계로 인해 해당 기능을 완전한 형태로 구현하지 못했지만, 현재 구현된 Tree Based Architecture는 총기뿐만 아니라 캐릭터나 다른 장비에도 동일한 구조를 적용할 수 있도록 설계되어 있습니다.

// 03 — DATA ARCHITECTURE

Tree Based Data Structure

01

ItemPDA

Primary Data Asset을 기반으로 각 아이템의 Mesh, Animation, Socket, Gameplay Tag 등의 원본 데이터를 관리합니다.

02

ItemObject

실제 트리 구조를 구성하는 런타임 객체입니다. 각 객체는 자신의 Data와 Child Item을 가지고 부모-자식 관계를 구성합니다.

03

ItemManager

AssetManager를 기반으로 필요한 아이템 데이터를 검색하고 로드하며 Default Tree 생성과 Layout 저장 및 불러오기 등을 담당합니다.

04

Gameplay Tags

아이템의 종류를 Tag로 분류하여 특정 Socket에 장착 가능한 장비를 제한하거나 원하는 아이템을 검색할 수 있도록 구현했습니다.

// 04 — LAYOUT SYSTEM

Layout Save & Load

01

JSON Serialization

사용자가 제작한 총기 Layout을 JSON 형태로 저장하여 기존 데이터와 분리된 형태로 관리합니다.

02

Name Based Loading

Layout에는 실제 객체 전체를 저장하는 대신 각 Tree Node가 가지고 있는 데이터의 이름을 저장하고 이를 이용해 다시 Tree를 구성합니다.

03

Version Compatibility

이후 데이터 구조가 변경되더라도 존재하지 않는 Node는 부모 데이터가 가진 기본값을 사용하여 기존 Layout을 최대한 유지할 수 있도록 설계했습니다.

04

Thumbnail Generation

Layout 저장 시 현재 설정된 총기의 Thumbnail을 자동으로 생성하여 저장된 Layout을 UI에서 쉽게 구분할 수 있도록 구현했습니다.

// 05 — UI SYSTEM

Weapon Modding UI

01

ItemListWidget

아이템을 타입별 Tree 구조로 필터링하여 표시하고 Default와 Layout 항목을 선택할 수 있도록 구성했습니다.

02

ItemModifyWidget

Display Actor의 Socket 위치를 기반으로 화면에 모딩 UI를 배치하고 실제 장비 변경 사항을 시각적으로 반영하도록 구현했습니다.

03

Tree Filtering

Gameplay Tag를 기반으로 특정 종류의 아이템을 검색하고 Tree 구조를 통해 상위 및 하위 장비 관계를 확인할 수 있도록 구현했습니다.

04

Display Actor

Tree의 변경 사항을 실제 3D 모델에 즉시 반영하여 사용자가 장비를 변경하면서 결과를 확인할 수 있도록 구현했습니다.

// 06 — UI POSITIONING

Dynamic Modding UI Placement

기존 게임의 총기 모딩 UI에서는 총기를 회전시키거나 측면에서 바라볼 경우 Socket과 UI를 연결하는 선이 서로 겹치는 문제가 발생했습니다.

이 문제를 해결하기 위해 화면을 Normalized Device Coordinates 방식으로 생각하여 화면의 가로세로 비율을 정규화하고, 화면 중심을 기준으로 가상의 타원을 구성했습니다.

각 Socket은 실제 화면상 위치에서 Socket 방향에 따라 가상의 타원 바깥쪽으로 배치되도록 계산했습니다.

하지만 총구나 총열처럼 동일한 방향에 여러 Socket이 존재하는 경우 UI가 겹치는 문제가 발생했습니다. 이를 해결하기 위해 각 Slot의 기본 각도를 계산한 뒤 겹치는 Slot을 탐색하고, 두 Slot 사이의 필요한 최소 각도를 Binary Search 방식으로 계산하여 서로 겹치지 않도록 각도를 조정했습니다.

또한 359°와 1°처럼 각도의 경계에서 발생하는 문제를 해결하기 위해 가장 큰 Angular Gap을 기준으로 각도를 Unwrap하여 처리했습니다.

// 07 — DEVELOPMENT TOOL

ItemDataEUW

01

Editor Utility Widget

프로그래머가 아닌 개발자도 Item Data Asset을 쉽게 추가하고 삭제할 수 있도록 Editor Utility Widget을 제작했습니다.

02

Asset Management

아이템 데이터를 관리하는 작업을 에디터에서 쉽게 수행할 수 있도록 개발용 UI를 구성했습니다.

03

Thumbnail Generator

아이템의 3D 모델을 기반으로 Thumbnail을 자동 생성할 수 있는 기능을 구현했습니다.

// 08 — SUMMARY

What I Worked On

이 프로젝트에서 저는 Tree Based Gun의 핵심 시스템을 설계하고 구현했습니다.

특히 ItemPDA와 ItemObject를 기반으로 한 Tree 구조와 ItemManager를 통한 데이터 관리 시스템을 구현했으며, Layout 저장 및 불러오기 과정에서 데이터 구조 변경에 대응할 수 있도록 기본값 기반의 데이터 복구 구조를 설계했습니다.

또한 Display Actor와 ItemModifyWidget을 연결하고 Socket 위치를 기반으로 동적으로 UI를 배치하는 알고리즘을 직접 설계하고 구현했습니다.

개발 과정에서는 Editor Utility Widget을 제작하여 Item Data Asset을 보다 쉽게 관리할 수 있도록 개발 환경도 개선했습니다.
