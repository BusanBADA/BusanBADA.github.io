PORTFOLIO / PROTOTYPE

Advanced Character Movement

Unreal Engine Character Movement Component 기반의 Titanfall 스타일 Advanced Movement Prototype

Unreal Engine C++ Multiplayer Movement System Solo Project 3 Weeks
// 01 — OVERVIEW

About the Project

이 프로젝트는 Arsenal에 Jetpack 기반의 고기동성 캐릭터를 추가하기 위해 시작한 Advanced Character Movement Prototype입니다.

Titanfall의 Pilot Movement에서 영감을 받아 Unreal Engine의 기본 Character Movement Component를 확장하여 Sprint, Slide, Wall Run, Climb, Ledge Grab 등의 이동 기능을 구현했습니다.

단순히 로컬 환경에서 동작하는 Movement System이 아니라 Multiplayer 환경에서 사용할 수 있도록 Movement Replication과 Client Prediction을 고려하여 구현하는 것을 주요 목표로 삼았습니다.

각 이동 방식은 Custom Movement Mode를 기반으로 구현하고, 서버와 클라이언트 사이에서 동일한 이동 결과를 유지하면서 부드러운 플레이어 이동을 구현하는 데 집중했습니다.

// 02 — IMPLEMENTATION

What I Worked On

MOVEMENT SYSTEM
01

Sprint

캐릭터의 Sprint Movement를 구현하고 Multiplayer 환경에서 상태가 정상적으로 Replication되도록 구현

02

Slide

지면의 방향과 캐릭터 속도를 기반으로 Surface를 따라 이동하는 Custom Slide Movement 구현

03

Wall Run

벽의 방향을 감지하고 캐릭터가 벽을 따라 이동하도록 Side Wall Run Movement 구현

04

Wall Tracking

벽면의 방향을 지속적으로 추적하여 Wall Run 중 자연스럽게 벽을 따라 이동하도록 구현

05

Climb

전방의 벽을 감지하여 벽을 오를 수 있는 Custom Climb Movement 구현

06

Stamina System

Climb와 같은 이동 기능에 Stamina를 적용하여 무제한 이동을 방지하고 Gameplay Resource로 활용

07

Ledge Grab

캐릭터 전방의 Ledge를 감지하고 Custom Movement State를 통해 Ledge Grab 기능 구현

NETWORKING & REPLICATION
01

Movement Replication

Custom Movement State와 입력 상태가 Multiplayer 환경에서 정상적으로 동기화되도록 구현

02

Client Prediction

Unreal Engine의 Client Prediction 구조를 이해하고 Custom Movement에서도 예측 이동이 자연스럽게 동작하도록 구현

03

Server Synchronization

Server와 Client 간 Movement 결과의 차이를 최소화하여 Multiplayer 환경에서 캐릭터 Jitter를 방지

ENGINE ANALYSIS
01

Character Movement Analysis

Unreal Engine Character Movement Component의 내부 구조와 Character Class와의 강한 결합 구조 분석

02

Input Replication Limitation

Character Movement Component의 Input State Replication 구조와 8-bit Input Flag의 제한 사항 분석

03

Movement Scalability

Skating, Grappling 등의 추가적인 Custom Movement를 구현할 때 기존 Character Movement Component가 가지는 확장성 문제 분석

04

Mover Plugin Research

Unreal Engine의 새로운 Movement Architecture인 Mover Plugin을 조사하고 기존 시스템의 확장성 문제에 대한 대안으로 검토

// 03 — RESULT

Result & Conclusion

최종적으로 Sprint, Slide, Wall Run, Climb, Ledge Grab 등의 Custom Movement를 Multiplayer Replication과 Client Prediction을 지원하는 형태로 구현했습니다.

구현 과정에서 Unreal Engine의 Character Movement Component가 가지고 있는 Input Replication 및 확장성의 한계를 직접 경험했고, 단순히 기능을 추가하는 것보다 Movement Architecture 자체의 확장성이 중요하다는 결론을 내렸습니다.

특히 향후 Skating이나 Grappling Hook과 같은 추가적인 Custom Movement를 지원하기 위해서는 기존 Character Movement Component를 계속 확장하는 방식보다 새로운 Movement Architecture가 필요하다고 판단했습니다.

이후 Unreal Engine에서 제공하는 Mover Plugin을 조사하고 해당 시스템으로 이동하면서 본 Prototype을 마무리했습니다.
